## Как обновлять

1. Править `features.json` (название, цель, что сделано, как работает, пошаговая инструкция `steps`, база).
2. Закоммитить и запушить в `main`.
3. GitHub Pages подхватит изменения автоматически.

По просьбе «обнови страницу доработок» агент обновляет JSON и пушит сюда.
